# Логотипы площадок

Положите сюда файл с именем площадки - и он заменит монограмму в интерфейсе
без правок кода.

```
src/renderer/platforms/depop.svg
src/renderer/platforms/poshmark.svg
src/renderer/platforms/vinted.svg
```

Имя файла - это `id` площадки из каталога `PLATFORMS` (`src/renderer/app.js`),
расширение строго `.svg`.

Как это работает: аватарка всегда рисует монограмму в цвете площадки, а
картинка вставляется поверх только после успешной загрузки. Файла нет - на
экране остаётся буква, ничего не ломается и не мигает битым значком.

Требования к файлу:

- квадратный `viewBox` (значок обрезается по `object-fit: cover`);
- собственный фон внутри - подложки под картинкой не будет;
- никаких внешних ссылок и скриптов внутри SVG: политика безопасности
  приложения их всё равно не пропустит.

Своих логотипов в репозитории нет намеренно: это чужие товарные знаки, и
рисовать их по памяти нельзя. Берите официальные файлы из брендбуков площадок.
